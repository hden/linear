# Linear

Linear is an open-source Turso sync server.

Give each customer their own database, custom schema, and environment to clone.
Clients work locally and sync with Linear. Read [why Linear](docs/for-agents.md)
for Database-per-Tenant and Vault-per-Tenant, or browse the [documentation index](llms.txt).

Verified with [`@tursodatabase/sync` 0.8.3](docs/turso-compatibility.md).
